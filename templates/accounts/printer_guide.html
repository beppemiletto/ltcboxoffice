Guida Installazione Print Bridge Vai al Test Stampante

Il Print Bridge è un piccolo programma che gira sul PC della cassa e permette al sito di stampare i biglietti con i posti a sedere sulla stampante USB locale. Va avviato prima di aprire una sessione di cassa.

Scarica i file necessari
print_bridge.py check_endpoints.py

Salva i file nella cartella print_bridge che creerai nei passi seguenti. Il file print_bridge.json lo crei tu con la configurazione della tua stampante (vedi sotto).

  • Linux
  • Windows
Passo 1 — Crea la cartella e copia i file
mkdir ~/print_bridge
cd ~/print_bridge
# copia qui print_bridge.py e check_endpoints.py scaricati sopra
Passo 2 — Crea l'ambiente virtuale e installa le dipendenze
python3 -m venv ~/print_bridge_env
source ~/print_bridge_env/bin/activate
pip install pyusb
Passo 3 — Permessi USB (necessario su Linux)

Senza questo passaggio il bridge non riesce ad accedere alla stampante senza sudo.

sudo tee /etc/udev/rules.d/99-escpos.rules <<'EOF'
SUBSYSTEM=="usb", ATTRS{idVendor}=="XXXX", ATTRS{idProduct}=="YYYY", MODE="0666"
EOF
sudo udevadm control --reload-rules && sudo udevadm trigger

Sostituisci XXXX e YYYY con vendor e product ID della tua stampante (es. 0471 e 0055 per Philips POS). Per trovare gli ID: lsusb con la stampante collegata.

Passo 4 — Trova l'endpoint corretto della stampante
source ~/print_bridge_env/bin/activate
cd ~/print_bridge
python check_endpoints.py

Cerca la riga BULK OUT (es. ep=0x02 OUT BULK). Il numero esadecimale (es. 2) è il valore di out_ep da usare nel JSON.

Passo 5 — Crea print_bridge.json

Crea il file ~/print_bridge/print_bridge.json con questo contenuto, adattando i valori:

{
  "type": "usb",
  "vendor": "0xXXXX",
  "product": "0xYYYY",
  "out_ep": 2,
  "interface": 0
}
Avvio
source ~/print_bridge_env/bin/activate
cd ~/print_bridge
python print_bridge.py

Il bridge stampa Trovata: SI se la stampante è riconosciuta.

Stop
pkill -f print_bridge.py
Su Windows non servono regole udev. È necessario avere Python 3.9+ installato (python.org) con l'opzione "Add Python to PATH" spuntata.
Passo 1 — Crea la cartella e copia i file

Apri il Prompt dei comandi (cmd) o PowerShell:

mkdir %USERPROFILE%\print_bridge
cd %USERPROFILE%\print_bridge
rem copia qui print_bridge.py e check_endpoints.py scaricati sopra
Passo 2 — Crea l'ambiente virtuale e installa le dipendenze
python -m venv %USERPROFILE%\print_bridge_env
%USERPROFILE%\print_bridge_env\Scripts\activate
pip install pyusb libusb-package

Su Windows è necessario anche libusb-package che include il driver libusb senza dover installare nulla a livello di sistema.

Passo 3 — Trova l'endpoint corretto della stampante
%USERPROFILE%\print_bridge_env\Scripts\activate
cd %USERPROFILE%\print_bridge
python check_endpoints.py

Cerca la riga BULK OUT (es. ep=0x02 OUT BULK). Il numero (es. 2) è il valore di out_ep.

Se la stampante non viene trovata su Windows potrebbe essere necessario installare il driver WinUSB tramite Zadig: apri Zadig, seleziona la stampante POS, scegli driver WinUSB, clicca Install Driver.
Passo 4 — Crea print_bridge.json

Crea il file print_bridge.json nella cartella print_bridge:

{
  "type": "usb",
  "vendor": "0xXXXX",
  "product": "0xYYYY",
  "out_ep": 2,
  "interface": 0
}

Per trovare vendor e product ID su Windows: apri Gestione dispositivi, tasto destro sulla stampante → Proprietà → Dettagli → ID hardware. Oppure usa check_endpoints.py che li mostra direttamente.

Avvio
%USERPROFILE%\print_bridge_env\Scripts\activate
cd %USERPROFILE%\print_bridge
python print_bridge.py

Lascia aperta questa finestra del terminale finché la cassa è in uso.

Stop
taskkill /F /IM python.exe /FI "WINDOWTITLE eq print_bridge*"

Oppure chiudi semplicemente la finestra del terminale dove gira il bridge.

Risoluzione problemi
ProblemaCausaSoluzione
Bridge non parte: Address already in use Bridge già in esecuzione Linux: pkill -f print_bridge.py
Windows: chiudi il terminale precedente
Bridge parte ma dice Trovata: NO Stampante non collegata o permessi mancanti Verifica cavo USB e alimentazione. Su Linux: controlla le regole udev. Su Windows: installa WinUSB con Zadig.
Bridge OK ma non stampa nulla out_ep sbagliato nel JSON Esegui check_endpoints.py e aggiorna out_ep nel JSON con il valore BULK OUT corretto
Pagina test dice "Bridge non raggiungibile" Bridge non avviato o bloccato dal browser Avvia il bridge. Se usi HTTP (non HTTPS) il browser potrebbe bloccare localhost — usa sempre HTTPS
Pagina test OK ma cassa non stampa Sessione di cassa aperta prima del bridge Avvia sempre il bridge prima di aprire la sessione di cassa
